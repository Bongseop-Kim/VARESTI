## 18. 체크리스트 (자동 검사기 전까지 손으로)
**이야기**
- [ ] 숨은 전제가 모든 어긋남을 설명하는가
- [ ] 숨은 전제가 마지막 장에서 반드시 드러나는가
- [ ] 범인 찾기 말고 진짜 이야기가 있는가
- [ ] 모든 인물(주인공 포함)에게 비밀이 있는가

**1장 (무료)**
- [ ] NPC를 휘둘러 진실 조각을 얻는 경험이 최소 1번 있는가
- [ ] 첫 어긋남(나는 사실대로 말했는데 거짓말이라 함)이 있는가
- [ ] 궁금한 지점에서 끝나는가

**구조**
- [ ] 모든 진실 조각에 획득 경로가 있는가
- [ ] 모든 엔딩에 도달할 수 있는가
- [ ] 모순 목록의 거짓말마다 실토까지 가는 길이 있는가
- [ ] 엔딩 도감 힌트가 숨은 전제를 흘리지 않는가
