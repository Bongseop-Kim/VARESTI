# VARESTI

NPC와 함께하는 1인 머더미스터리 모바일 게임. 서버 없이 로컬에서 동작.

> 모바일 게임을 가장한 소설. NPC들을 휘둘러서 → 비밀을 파헤치고 → 다양한 엔딩을 본다
>
> 밝혀지는 진실이 곧 보상. 승리·점수는 목적이 아님

## 핵심
- **NPC 선동**: NPC들을 교착·혼란·선동해 원하는 방향으로 휘두르기
- **숨겨진 진실 발견**: 시나리오의 스토리를 진실 조각으로 하나씩 밝혀내는 것이 목표
- **멀티 엔딩**: 진실은 고정, 결말은 플레이마다 달라짐
- **탐정이 아닌 용의자**: 남의 비밀을 캐면서 내 비밀을 지킴. 내가 범인일 수도 있음
- **1인 플레이**: 나머지 배역은 전부 NPC. 이탈·트롤 없이 게임에만 몰입
- **채팅 없는 추리**: 심문·추궁, 단서 제시, 귓속말로 캐고, NPC의 압박을 막아냄
- **거짓말 설계**: 알리바이를 직접 짜고, 모순을 피하며 끝까지 속이기
